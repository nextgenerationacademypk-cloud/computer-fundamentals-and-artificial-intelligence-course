## 2. Recommended genuine screenshots

Capture screenshots on an academy training computer using the same Windows version students will use. Suggested locations:

| 6 | Settings > System > About | Find processor, RAM, system type and Windows edition |

## 3. Screenshot capture checklist

Before taking a screenshot:
1. Use an academy-owned training account and non-confidential sample data.
2. Close private documents, browser tabs, email, chat, and student records.
3. Remove notifications that could reveal names or messages.
4. Do not show passwords, product keys, serial numbers, device IDs, or personal account details.
5. Use the same Windows version as the classroom wherever possible.
6. Capture only the relevant area; avoid unnecessary clutter.
7. Check text is readable at normal Markdown viewing size.
8. Add a caption and useful alternative text when adding the image to a lesson.

## 4. Photograph standards

For peripheral photographs:
- Use clear, well-lit photographs of actual academy devices.
- Photograph one device at a time against a plain background.
- Include a second close-up only when a port or connector needs identification.
- Do not imply that one connector design is universal across all computers.
- Add labels in Markdown or a separate diagram rather than placing tiny text over a photo.

## 6. Copyright, privacy and accessibility

- Prefer academy-created photographs and screenshots.
- If an external image is used, verify its license permits the intended use and include attribution.
- Do not copy textbook or commercial training screenshots without permission.
- Provide descriptive alt text; do not use file names as the only description.
- Do not use colour alone to communicate meaning.
- Keep images clear and useful; avoid decorative images that do not teach a concept.

**Important:** Do not create fake Windows screenshots. If an authentic screenshot is not yet available, keep the written steps and conceptual diagram; add the real screenshot after it is captured and reviewed.
