**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Week:** 2 — Windows and Computer Operations  
**Suggested total:** 50 marks

## 1. Assessment overview

| Component | Marks |
|---|---:|
| Written quiz | 15 |
| Practical skills assessment | 25 |
| Homework and safe-work habits | 10 |
| **Total** | **50** |

Use the assessment to check both technical understanding and safe independent practice. Students should not be penalized for using simple English when the meaning is correct.

## 2. Written quiz — 15 marks

Select 15 questions from WEEK-02-QUIZ-BANK.md. Recommended coverage:
- CPU, RAM, storage and system information: 3 marks.
- Input, output, storage and connections: 3 marks.
- Operating system and Windows navigation: 3 marks.
- Settings, accounts and security: 3 marks.
- Files, folders, ZIP and backup: 3 marks.

Award one mark per correct response. For short answers, accept equivalent wording.

## 3. Practical skills assessment — 25 marks

Use an academy computer and sample files. Assess one student at a time or in small supervised groups. Do not ask students to make unauthorized system changes.

| Skill | Evidence | Marks |
|---|---|---:|
| Find basic specifications | Locate processor, installed RAM, system type, and Windows edition | 3 |
| Observe Task Manager | Find CPU, Memory, and Disk views without changing settings | 3 |
| Identify peripherals and ports | Correctly classify at least six devices and identify common connections | 4 |
| Navigate Windows | Open Start, File Explorer, switch windows, minimize/restore and lock when instructed | 4 |
| Explore Settings safely | Locate display, sound, network, accounts, update, and security areas without unsafe changes | 3 |
| Organize files and folders | Create the required course folder structure and use clear names | 4 |
| File operations and ZIP | Copy, move, rename, restore a practice file, and create/extract a ZIP | 4 |
| **Total** | | **25** |

### Practical marking guidance

- Full marks: completes task correctly and independently while following safety instructions.
- Partial marks: completes with a prompt or makes a minor recoverable error.
- No marks for a task: cannot complete it or uses an unsafe method after correction.
- Stop an activity immediately if the student risks deleting real work, exposing private data, disabling security, or damaging equipment.

## 7. Common errors and recommended follow-up

| Common difficulty | Suggested follow-up |
|---|---|
| Confuses RAM and storage | Repeat the working-desk and filing-cabinet analogy; ask student to explain where an unsaved file is held |
| Calls a USB port a storage device | Show a port and a flash drive side by side |
| Closes an app instead of minimizing it | Repeat window-control practice |
| Changes settings without permission | Re-teach the approval process and reversible-change routine |
| Renames an extension expecting conversion | Demonstrate file name vs file format using safe sample copies |
| Removes USB while copying | Repeat the safe-eject demonstration using a practice file |
| Cannot organize folders | Rebuild the course folder structure with guided prompts |

## 8. Week 2 completion criteria

A student is ready to progress when they can:
- Explain the roles of CPU, RAM, and storage.
- Identify common input, output, and storage devices.
- Navigate the Windows desktop and open common settings areas.
- Organize course files and perform basic file operations.
- Use removable storage and shared computers safely.

Students who need more practice should receive a short supervised catch-up session before Week 3.
