# Week 2 — Windows and Computer Operations

**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Lessons:** 6–10 | **Duration:** 5 lessons × 120 minutes = 10 guided hours

## Week purpose

Students move from understanding computer components to operating a Windows computer confidently. They learn to inspect basic specifications, identify and connect peripherals, navigate Windows, explore common settings safely, and organize course files.

## Required equipment and preparation

- Windows training computers with student accounts.
- One instructor demonstration computer.
- Keyboard, mouse, monitor, headset/microphone, printer or projector if available.
- Approved training USB drives and non-confidential practice files.
- Optional sample HDD and SSD for comparison.
- Windows version and Settings layout checked before the lesson.
- A backup of any training computer that will be used for demonstrations.

## Safety and privacy rules

- Students must not change system-level settings, install software, disable security tools, or modify accounts without instructor permission.
- Use assigned student accounts; never share passwords.
- Use only academy-approved USB drives and practice files.
- Do not delete real student work or use permanent deletion in beginner exercises.
- Eject removable storage safely after copying is complete.
- Protect screenshots and photographs from exposing private information.

## Week 2 completion outcomes

Students should be able to:
- Explain CPU, RAM, and storage roles.
- Find basic system specifications and observe Task Manager.
- Identify input, output, and storage devices and common ports.
- Navigate Windows and use basic keyboard shortcuts.
- Find common settings and describe safe account/security practices.
- Create an organized course folder structure and manage practice files.
- Create and extract a ZIP archive and explain a basic backup plan.

## Quality and visual status

Conceptual diagrams are embedded in the relevant lesson files. Genuine screenshots of the academy's Windows version and actual classroom peripherals should be added after capture and privacy review. Do not substitute fabricated screenshots for real software interfaces.
