# Week 2 — Windows and Computer Operations

**Lessons:** 6–10

6. CPU, RAM, Storage and How Computers Work
7. Input, Output and Storage Devices
8. Operating Systems and Windows Basics
9. Windows Settings and Basic System Management
10. File Explorer, Files and Folders

Practical emphasis: inspect system specifications, use Task Manager, identify peripherals, navigate Windows, adjust approved settings, organise files and folders, compress files and safely use removable storage.

Safety: students must not change system-level settings, install software, delete system files or modify accounts without instructor permission.
