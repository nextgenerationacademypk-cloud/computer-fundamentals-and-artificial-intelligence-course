# Week 2 — Quiz Answer Key (Instructor Only)

**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Access:** Instructor reference. Do not distribute with student handouts.

Accept equivalent simple-English answers when the technical meaning is correct. Reward explanation and safe decision-making, not memorized wording.

## Lesson 6 — Suggested answers

1. The CPU executes program instructions and performs calculations and control tasks.
2. RAM holds programs and data currently in use; its contents are normally lost when power is turned off.
3. RAM is temporary working memory. Storage keeps files and programs for long-term use.
4. The operating system reads program data from storage, loads required parts into RAM, and the CPU executes instructions.
5. An HDD uses rotating magnetic disks; an SSD uses flash memory and has no rotating disk parts.
6. A CPU core is a processing unit within the CPU that can execute instructions.
7. A byte is usually eight bits.
8. Memory usage changes as applications and services use or release RAM.
9. Settings > System > About, or Task Manager > Performance > Memory.
10. The lesson is for observation. Changing settings can affect the computer or disrupt other users.

## Lesson 7 — Suggested answers

1. A peripheral is a device connected to a computer to provide input, output, storage, or communication.
2. Keyboard, mouse, scanner, microphone, webcam.
3. Monitor, printer, speakers, projector.
4. It displays information and detects touch input.
5. A USB port is a connection point; a USB flash drive is a storage device.
6. HDMI carries digital video and usually audio to a compatible display.
7. Ethernet provides a wired network connection.
8. Safe ejection helps prevent removal while data is still being written or the drive is in use.
9. Stop and check the connector and port. Never force it; ask the instructor.
10. Unknown drives may contain malware or unsafe files.

## Lesson 8 — Suggested answers

1. An OS manages hardware and provides services and an interface for applications and users.
2. Windows, macOS, Linux, Android, or iOS.
3. The main workspace shown after signing in.
4. It helps access pinned and open applications and other controls.
5. It hides the window while the application remains open.
6. Minimize hides a window; close ends the window or application (save work first).
7. Windows + E.
8. Windows + L.
9. Sign out ends the user session; shut down turns off the computer through Windows.
10. Unsaved work may be lost when applications close.

## Lesson 9 — Suggested answers

1. Windows + I.
2. Resolution, brightness, scale, text size, and display arrangement where supported.
3. Wi-Fi is wireless; Ethernet uses a network cable.
4. It affects timestamps, websites, security certificates, and scheduled tasks.
5. A standard user has limited system-changing permissions; an administrator can make major system changes.
6. Shared passwords reduce account security and make it difficult to know who performed an action.
7. It provides operating-system updates and security fixes.
8. They help protect the computer from malware and unauthorized network access.
9. Deny or avoid unnecessary permission and ask the instructor if unsure.
10. Record the original value, make one approved reversible change, test it, and restore it if needed.

## Lesson 10 — Suggested answers

1. A file stores information; a folder organizes files and other folders.
2. It helps browse drives, folders, and files and manage them.
3. The part of a file name after the final dot that often indicates its format.

## Practical scenario — Marking guidance

1. Observe Memory and/or CPU in Task Manager. Many open applications can use RAM and processing time. Accept disk activity if explained appropriately.
2. The copy may be incomplete or data may be damaged. Finish copying, close files, use Eject/Safely Remove, wait for confirmation, then remove.
3. Output device. It presents visual information from the computer.
4. Lock the computer (Windows + L).
5. No. The extension change does not convert the file's format.
6. Check Recycle Bin for a restorable local file. Do not empty it or permanently delete anything.
7. Do not plug it in. Give it to the instructor or follow academy lost-device policy.
8. Ask permission, record the original setting, and make only an approved change.

## Suggested marking

- Full credit: correct answer with an accurate explanation where requested.
- Partial credit: correct main idea but incomplete explanation.
- No credit: incorrect, unsafe, or blank response.

For practical safety questions, an unsafe recommendation should not receive full credit even if the technical term is correct.
