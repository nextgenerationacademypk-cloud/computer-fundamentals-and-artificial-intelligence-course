# Diagrams and Visual Resources

This folder is reserved for original diagrams, annotated screenshots, printable reference sheets and other visuals used by the lessons.

Visual standards:
- Use clear labels and readable text.
- Prefer original or appropriately licensed assets.
- Add source and licence/attribution details for third-party assets.
- Remove personal information from screenshots.
- Keep screenshots consistent with the software version used in class.
- Provide a short text explanation so the learning does not depend on an image alone.

**Development status:** Folder established; visual assets are to be created or curated.
