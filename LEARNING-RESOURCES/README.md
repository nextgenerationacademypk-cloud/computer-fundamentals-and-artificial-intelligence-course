# Learning Resources

This section will collect reliable external references and optional practice resources.

Resource selection standards:
- Prefer official vendor documentation and trusted educational sources.
- Check links before each course delivery.
- State whether a resource is optional or required.
- Explain any account, age, region, payment or internet requirements.
- Provide an offline or no-account alternative where possible.
- Never require students to bypass service restrictions or share credentials.
