# Learning Resources

This folder provides official and beginner-friendly external resources that support the eight-week course.

- [Course Resource Library](COURSE-RESOURCE-LIBRARY.md) — curated links for Windows, Office, internet safety, AI and prompt engineering, graphic design/video, web development, accessibility, GitHub and deployment.

## How to use these links

The course lesson notes and instructor demonstrations remain the primary learning path. External resources are optional support. Instructors should check links, product interfaces, account eligibility, regional availability, licensing and pricing before each course delivery.

Do not require students to purchase a subscription for a core learning outcome. Prepare offline alternatives for lessons that depend on online services.

**Development status:** Curated official resource library added. Links and service availability should be rechecked before teaching.
