# Course Resource Library — Official and Beginner-Friendly References

**For:** Next Generation Academy students and instructors  
**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Last link review:** 7 November 2026

These resources support the course lessons. The course notes and instructor demonstrations remain the primary learning path. External websites may change their menus, features, pricing, age rules or availability. The instructor should check each link and the relevant terms before class.

## 8. How to use an external resource well

When using a tutorial or help page:
1. Check who published it.
2. Check when it was updated.
3. Compare its instructions with the software version in the lab.
4. Follow only steps relevant to the lesson.
5. Ask the instructor before installing software or changing security, disk or network settings.
6. Record the title and link if you use it in an assignment.

## 9. Instructor link and access check

Before each course delivery:
- [ ] Open the links needed for the upcoming week.
- [ ] Check that the page is still official and relevant.
- [ ] Check account age, regional and plan restrictions for AI tools.
- [ ] Confirm the academy can legally and practically use the software.
- [ ] Prepare offline alternatives and screenshots where appropriate.
- [ ] Do not require a student to purchase a subscription for a core learning outcome.

**Resource policy:** Links are learning aids, not endorsements. The academy should choose tools based on student safety, accessibility, affordability, privacy and educational value.
