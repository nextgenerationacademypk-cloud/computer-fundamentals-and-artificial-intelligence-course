## Part A — Written knowledge quiz (20 marks)

**Instructions:** Answer all questions. Each question is worth 2 marks. Use simple, clear sentences.

1. Define a computer and name two tasks it can perform.
2. Explain the difference between data and information. Give one example of each.
3. Write the four stages of the IPOS cycle in the correct order.
4. Name two early calculating devices or systems and explain one contribution of either.
5. Match these technologies to their commonly taught generations: vacuum tubes, transistors, integrated circuits, microprocessors.
6. What is one important difference between a mainframe and a supercomputer?
7. Explain the difference between hardware and software.
8. Give one example each of system software and application software.
9. What are the functions of the CPU and RAM?
10. State two safety rules that must be followed before opening a desktop computer.

## Part B — Practical assessment (20 marks)

### Task 1: Identify components (10 marks)
Using a training desktop or labelled component display, identify any five of the following and state the function of each:
- Motherboard
- CPU
- RAM
- HDD or SSD
- PSU
- GPU
- Cooling fan/heatsink
- Network interface

**Scoring:** 1 mark for correct identification and 1 mark for a correct basic function for each of five components.

### Task 2: Identify devices and categories (4 marks)
Correctly classify four displayed items as input, output, storage, or processing devices. Award 1 mark per correct classification.

### Task 3: Explain a safe procedure (6 marks)
Explain the safe steps to prepare a desktop for internal inspection. Award up to 1 mark for each:
- Save work and shut down correctly.
- Switch off and unplug power.
- Follow the lab's ESD procedure.
- Handle components by their edges.
- Keep liquids and loose objects away.
- Never open the PSU or work inside a powered computer.

## Part C — Homework and participation (10 marks)

Use the following evidence-based rubric:
- Labelled system-unit diagram with at least eight components: 0–4 marks.
- Correct component functions: 0–2 marks.
- HDD vs SSD comparison: 0–2 marks.
- Safe participation, care of equipment, and completion of assigned class activities: 0–2 marks.

## Instructor answer guide — Part A

1. A computer is an electronic device that accepts data, processes it using instructions, produces output, and can store results. Examples: calculations and document creation.
2. Data is raw facts; information is processed, organized data. Example: individual marks are data; a class average report is information.
3. Input → Processing → Output → Storage.
4. Examples: abacus, Pascaline, Analytical Engine design, punched-card tabulating system. Award credit for a valid explanation.
5. Vacuum tubes—first; transistors—second; integrated circuits—third; microprocessors—fourth.
6. Mainframes are designed for high-volume transaction processing and many users; supercomputers are designed for extremely demanding calculations and simulations.
7. Hardware is physical equipment; software is programs and instructions.
8. System software: Windows or a device driver. Application software: Word processor, browser, spreadsheet, etc.
9. CPU executes instructions and performs processing; RAM temporarily holds active programs and data.
10. Any two valid rules, such as shut down, unplug power, use ESD precautions, never open PSU, never work on a powered computer.

## Practical marking notes

- Accept equivalent correct wording.
- Do not award a full function mark for simply repeating a component's name.
- Assess safety understanding seriously. Stop any unsafe action immediately.
- Use a spare training desktop or labelled parts, not students' personal devices.
- Record observed skills, not assumptions based only on written answers.

- **Secure:** Ask the student to explain a component or IPOS example to a classmate.
