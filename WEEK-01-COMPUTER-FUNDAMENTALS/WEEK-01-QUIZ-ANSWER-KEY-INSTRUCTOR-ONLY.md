# Week 1 — Quiz Answer Key (Instructor Only)

**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Access:** Instructor reference. Do not include this file in student handouts.

Accept equivalent correct wording. Assess understanding, not memorization of one exact sentence.

## Lesson 1 — Suggested answers
1. A computer is an electronic device that accepts data, processes it using instructions, produces output, and can store results.
2. Data is raw facts; information is data processed or organized so it is useful.
3. Input → Processing → Output → Storage.
4. Input: marks typed into a spreadsheet. Output: total or average displayed or printed.
5. The abacus is a counting tool used to help perform arithmetic.
6. Babbage's designs included important ideas for programmable mechanical computing and influenced later thinking about general-purpose computers.

## Lesson 2 — Suggested answers
1. Vacuum tubes.
2. Transistors.
3. An integrated circuit is a small chip containing interconnected electronic components.
4. A microprocessor is a processor implemented on a chip.
5. Fourth generation in the common framework.
6. Dates and definitions vary by textbook; technology developed gradually and not every computer fits neatly into one category.

## Lesson 3 — Suggested answers
1. A desktop is usually designed to stay in one place and often has separate components; a laptop is portable and has a built-in screen, keyboard, touchpad, and battery.
2. A server is a computer that provides services or resources to other computers.
3. Extremely demanding calculations and simulations, such as scientific or climate modelling.
4. Examples: car control system, washing machine, router, smart television, industrial controller.
5. A workstation can provide stronger performance and professional capabilities for demanding design workloads.
6. A server, because it provides website files or application services to users over a network.

## Lesson 4 — Suggested answers
1. Hardware is the physical equipment of a computer.
2. Software is programs and instructions used by a computer.
3. Keyboard, mouse, scanner, microphone, webcam.
4. Monitor, printer, speakers, projector.
5. An operating system manages hardware and provides services for applications and users.
6. A driver helps the operating system communicate with a hardware device.
7. A web browser is application software.

## Lesson 5 — Suggested answers
1. The motherboard connects major components and allows them to communicate.
2. The CPU executes instructions and performs general-purpose processing.
3. RAM holds active programs and data temporarily; its contents are normally lost when power is removed.
4. An HDD stores data on rotating magnetic disks; an SSD uses flash memory and has no rotating disk.
5. The PSU converts incoming electrical power into the forms needed by computer components.
6. It helps remove heat and keep components within safe operating temperatures.
7. Examples: USB, HDMI, DisplayPort, Ethernet, audio, power.
8. To reduce electrical and equipment-damage risks; the instructor must follow the lab safety procedure.
9. A PSU can contain dangerous electrical components even when unplugged. It must not be opened by students.
10. Stop. Do not force it. Ask the instructor to check compatibility and orientation.

## Short scenario — marking guidance
1. Input: marks typed. Processing: total/average calculation. Output: result displayed/printed. Storage: workbook saved to a drive or approved cloud location.
2. A monitor is physical hardware. It displays output from software; it is not itself a program.
3. Stop immediately. RAM must be compatible and correctly aligned. Never force a module; ask the instructor.
4. A server is designed to provide services or resources to other computers over a network. A website can be hosted on a server.

## Suggested scoring
- Full credit: correct concept and relevant example where requested.
- Partial credit: main idea is present but explanation is incomplete.
- No credit: incorrect, unrelated, or blank answer.

Do not penalize students for using simple English if the technical meaning is correct.
