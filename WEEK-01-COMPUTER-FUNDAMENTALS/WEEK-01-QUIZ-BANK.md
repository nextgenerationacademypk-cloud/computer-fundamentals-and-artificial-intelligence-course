# Week 1 — Student Quiz Bank

**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Week:** 1 — Computer Fundamentals and Hardware

**Instructions:** Answer without looking at the answer key. Your instructor may use these questions for lesson checks, revision, or a weekly test.

## Lesson 1 — Introduction to Computers
1. In your own words, what is a computer?
2. What is the difference between data and information?
3. Write the four stages of the IPOS cycle in the correct order.
4. Give one example of input and one example of output when preparing a student marks sheet.
5. What was the abacus used for?
6. Why are Charles Babbage's designs important in computer history?

## Lesson 2 — Computer Generations and Evolution
1. Which main technology is associated with the first commonly taught generation?
2. What replaced vacuum tubes in the second generation?
3. What is an integrated circuit?
4. What is a microprocessor?
5. Which generation is commonly associated with the rise of personal computers?
6. Why should the five-generation framework be treated as a teaching model rather than an exact universal timeline?

## Lesson 3 — Types of Computers
1. Give two differences between a desktop and a laptop.
2. What is a server?
3. What kind of work is a supercomputer designed to perform?
4. Give two examples of embedded computers.
5. Why might a professional designer use a workstation?
6. A business needs a computer system to host its website. Which type is suitable, and why?

## Lesson 4 — Hardware and Software
1. Define hardware.
2. Define software.
3. Give three examples of input devices.
4. Give three examples of output devices.
5. What is an operating system?
6. What is the purpose of a device driver?
7. Is a web browser hardware or software? Explain.

## Lesson 5 — Inside the System Unit
1. What is the role of the motherboard?
2. What does the CPU do?
3. Why is RAM described as temporary working memory?
4. Give one difference between an HDD and an SSD.
5. What does a PSU do?
6. What is the purpose of a cooling fan or heatsink?
7. Name three external computer ports or connectors.
8. Why must a computer be shut down and disconnected from power before an approved internal inspection?
9. Why must students never open a PSU?
10. What should you do if a component does not fit easily?

## Mixed revision — Multiple choice

Choose one best answer for each question.

1. Which stage of IPOS means carrying out instructions on data?
   - A. Input
   - B. Processing
   - C. Output
   - D. Storage

2. Which item is application software?
   - A. CPU
   - B. RAM
   - C. Spreadsheet application
   - D. Motherboard

3. Which component is the main circuit board connecting major computer components?
   - A. Motherboard
   - B. Power supply
   - C. Cooling fan
   - D. SSD

4. Which device can provide both input and output?
   - A. Basic speaker
   - B. Touchscreen
   - C. Basic keyboard
   - D. Power cable

5. Which storage device uses flash memory and has no rotating disk?
   - A. HDD
   - B. SSD
   - C. Optical disc
   - D. Magnetic tape

6. Which action is unsafe?
   - A. Following the lab's ESD procedure
   - B. Disconnecting power before internal inspection
   - C. Opening a PSU to inspect its internal parts
   - D. Handling a component by its edges

## Short scenario questions
1. A teacher enters student marks into a spreadsheet. Identify one input, one processing action, one output, and one storage action.
2. A student says, "The monitor is software because it displays programs." Explain why this is incorrect.
3. A classmate tries to force a RAM module into a slot. What should you advise?
4. A school wants to run a website for students. Explain why a server is suitable.
