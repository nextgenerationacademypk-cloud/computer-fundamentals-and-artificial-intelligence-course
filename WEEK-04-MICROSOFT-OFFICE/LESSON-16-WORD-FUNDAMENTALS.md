# Lesson 16 — Microsoft Word Fundamentals

**Week:** 4 | **Duration:** 120 minutes | **Practical focus:** 80%

## Learning outcomes
By the end of this lesson, students can open Word, identify its main interface areas, create and save a document, edit text, format paragraphs, use lists, set basic page layout, check spelling and export a document as PDF.

## Key terms
Word processor, document, ribbon, tab, font, paragraph, alignment, margin, line spacing, bullet list, file format, PDF.

## 1. What is a word processor?
A word processor is an application used to create, edit, format, save and print text documents. Microsoft Word is widely used for letters, reports, CVs, forms and school work. LibreOffice Writer is a suitable alternative when Word is not available.

A document is not professional simply because it uses many colours or fonts. It should be readable, accurate, consistent and suitable for its purpose.

## 2. Understand the Word window
Common interface areas include:
- **Title bar:** shows the document name.
- **Quick Access Toolbar:** shortcuts such as Save and Undo (layout may vary).
- **Ribbon:** commands arranged in tabs such as Home, Insert and Layout.
- **Document area:** where you type and edit.
- **Status bar:** page and word information.
- **Zoom control:** changes how large the page appears on screen; it does not change printed size.

The exact interface can differ between Word versions and operating systems.

## 3. Create, save and reopen
1. Open Word and choose a blank document.
2. Type a short heading and paragraph.
3. Use Save As to select the course practice folder.
4. Give the file a clear name, such as `Student-Introduction.docx`.
5. Save in Word format so it remains editable.
6. Close and reopen it to confirm that the file was saved.

Save regularly. Use meaningful file names and keep a backup copy in the academy-approved location.

## 4. Enter and edit text
- Click in the document and type.
- Use Enter to start a new paragraph; do not press Enter repeatedly to create page spacing.
- Use Backspace or Delete carefully.
- Select text before changing its formatting.
- Use Undo to reverse an accidental change.
- Use Find to locate a word or phrase.
- Use Replace carefully; review replacements before saving.

## 5. Format text and paragraphs
The Home tab commonly contains font and paragraph tools.

**Character formatting:** font family, size, bold, italic, underline, font colour and text highlighting. Use a small, consistent set of styles.

**Paragraph formatting:** left, centre, right and justified alignment; bullets; numbering; indentation; and line spacing. Use paragraph spacing rather than repeated blank lines.

A useful beginner standard is one readable body font, a larger heading, consistent heading levels and sufficient white space. Avoid decorative fonts for long paragraphs.

## 6. Page setup
Use Layout or Page Layout controls to set:
- Paper size (commonly A4 in this course).
- Portrait or landscape orientation.
- Margins.
- Page breaks where a new section should begin.

Do not use many spaces or repeated Enter presses to push content to another page. Use page breaks and paragraph settings.

## 7. Spellcheck and review
Run spelling and grammar tools, but do not accept every suggestion automatically. Names, technical words and local terms may be flagged incorrectly. Read the whole document yourself. Check dates, phone numbers, names, punctuation and factual accuracy.

## 8. Save as PDF
PDF is useful when the recipient should view or print a stable layout. Keep the editable DOCX version as well. Use Export or Save As PDF, then open the PDF and inspect page breaks, images and readability.

## Guided practical — Create a one-page student introduction
Create a document containing:
- Title: My Student Profile
- Full name (use a practice name if sharing the file)
- Course and academy
- A short paragraph about learning goals
- A three-item bulleted list of skills to develop
- Date at the bottom

Format the title, use readable body text, set A4 page size, save as DOCX and export a PDF.

## 120-minute teaching plan
| Time | Activity |
|---|---|
| 0–20 min | Explain word processing, interface and document types |
| 20–35 min | Instructor demonstration: create, save, reopen |
| 35–70 min | Guided typing, selection, editing and formatting |
| 70–95 min | Paragraphs, lists and page setup |
| 95–110 min | Spellcheck, export PDF and inspect |
| 110–120 min | Review, questions and skill check |

## Understanding check
1. What is the difference between DOCX and PDF?
2. Why should you save with a meaningful file name?
3. What is the difference between font formatting and paragraph formatting?
4. Why is pressing Enter many times a poor page-layout method?
5. Does spellcheck guarantee that a document is correct?

## Homework
Create a one-page document titled **My Learning Goals**. Include a heading, two short paragraphs, a numbered list of three goals and a date. Submit both editable DOCX and PDF if available.

## Instructor notes
Demonstrate slowly on the projector, then let students repeat each step. Check that students can locate the saved file, not merely see it open. Provide a prepared practice paragraph for students who type slowly. Do not require students to disclose personal information; fictional details are acceptable.

- [ ] Edit and format text.
- [ ] Apply paragraph alignment and lists.
- [ ] Set page size and margins.
- [ ] Review spelling and export PDF.
