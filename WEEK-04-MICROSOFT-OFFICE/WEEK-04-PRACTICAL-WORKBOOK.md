## Activity 2 — Word: professional report
Create a two-page Academy Activity Report with three sections using heading styles, a sample timetable table, one approved image with suitable wrapping and alt text, header/footer and page numbers, one working hyperlink, and a table of contents if supported. Export PDF and inspect both files.

**Peer review:** Is the document readable? Are headings consistent? Are links working? Is the image stretched? Are page breaks sensible?

## Activity 3 — Excel: registration workbook
Create a fictional registration table with at least eight records. Columns: Student ID, Student Name, Course, Registration Date, City. Format as a table, set appropriate date and text formats, adjust column widths, sort by Student Name using the whole table, filter by City and clear the filter, freeze the header row, and save as XLSX.

## Activity 4 — Excel: formulas and marks
Create fictional marks for at least six learners. Use columns Student ID, Name, Subject 1, Subject 2, Subject 3, Total, Average and Result. Use SUM, AVERAGE, IF, MIN, MAX and COUNT. Copy formulas down, test one row manually, apply conditional formatting to low scores and create a column chart. Record formula errors and how you fixed them.

## Activity 5 — Excel: expense analysis
Create a fictional monthly expense table with Category, Planned Amount and Actual Amount. Calculate total planned and actual amounts, the difference and the largest expense. Create a suitable chart and explain one observation.

## Activity 6 — PowerPoint: technology safety
Create six slides: title and purpose; why computer safety matters; safe password/account habits; safe browsing/downloads; practical safety checklist; summary and sources. Use a consistent theme, readable text, one permitted visual, speaker notes on at least two slides and restrained effects. Present for two minutes.
