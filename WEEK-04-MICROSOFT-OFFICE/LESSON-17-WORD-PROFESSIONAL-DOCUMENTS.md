# Lesson 17 — Word Professional Documents

**Week:** 4 | **Duration:** 120 minutes | **Practical focus:** 80%

## Learning outcomes
Students can build a neat multi-section document using headings, tables, pictures, wrapping, headers, footers, page numbers, page breaks, hyperlinks and accessible document practices.

## Key terms
Styles, heading level, table, cell, row, column, text wrapping, header, footer, page number, hyperlink, table of contents, accessibility.

## 1. Plan before formatting
Identify the reader and purpose. A CV, academy report and timetable need different layouts. Organize content into sections before adding decoration. Check spelling, dates and facts.

## 2. Use styles and heading levels
Styles apply consistent formatting to headings and body text. Use Heading 1 for main sections and Heading 2 for subsections. Do not simply make every heading bold and large; built-in styles help navigation and can support an automatic table of contents.

To add a table of contents, apply heading styles first, then use the References tab's Table of Contents command. Update it after changing headings or page positions. The exact command location varies by version.

## 3. Create and format tables
Use Insert > Table. Tables are suitable for timetables, contact lists and structured information. Add or remove rows/columns as needed. Keep headings clear, avoid excessive merged cells, and ensure the table remains readable when printed. Do not use a table merely to force page layout.

## 4. Insert pictures and control wrapping
Use pictures that you own or are allowed to reuse. Add descriptive alternative text where supported. Use text wrapping options such as In Line with Text or Square when suitable. In Line with Text is often the most predictable for beginners. Resize from a corner to preserve proportions. Do not stretch faces or logos.

## 5. Headers, footers and page numbers
Headers and footers can contain document title, academy name or date. Page numbers help readers navigate longer documents. Keep them subtle and consistent. Avoid placing confidential student information in shared examples.

## 6. Page breaks and section awareness
Use Insert > Page Break to start a new page intentionally. A section break is different: it can allow a different layout or header/footer in another section. Teach section breaks as an introduction; advanced layouts can be revisited later.

## 7. Hyperlinks
Select meaningful text and insert a hyperlink. Link labels should explain the destination, such as “Academy website”, not “click here”. Test links before sharing. Avoid links to unknown downloads.

## 8. Accessibility and professional quality
- Use built-in heading styles in logical order.
- Use readable font sizes and strong text/background contrast.
- Add alternative text to meaningful images.
- Do not communicate meaning through colour alone.
- Use descriptive link text.
- Keep tables simple and identify header rows.
- Run spelling review and inspect the exported PDF.

## Guided practical — Academy activity report
Create a two-page report with:
1. Title and date.
2. Three sections using heading styles.
3. A table showing a sample activity schedule.
4. One approved academy image with suitable wrapping and alt text.
5. Header, footer and page numbers.
6. One working hyperlink to an approved public resource.
7. PDF export and final inspection.

Use fictional student names and sample information.

## 120-minute teaching plan
| Time | Activity |
|---|---|
| 0–20 min | Explain professional layout, styles and accessibility |
| 20–40 min | Demonstrate headings and table of contents |
| 40–65 min | Build and format tables |
| 65–85 min | Insert image, wrapping and alt text |
| 85–100 min | Headers, footers, page numbers and page breaks |
| 100–112 min | Hyperlinks, review and PDF export |
| 112–120 min | Peer review and reflection |

## Understanding check
1. Why use heading styles?
2. What is a table of contents based on?
3. Why should an image not be stretched?
4. What is alternative text?
5. When is a page break better than repeated blank lines?

## Homework
Prepare a two-page **Academy Information Sheet** using heading styles, one table, one approved image, page numbers and a working link. Submit DOCX and PDF.

## Instructor notes
Show one good and one poorly formatted document. Ask students to identify readability problems. Use only approved images and fictional records. If automatic TOC is unavailable in the installed version, assess heading styles and explain the feature rather than losing practical time.
