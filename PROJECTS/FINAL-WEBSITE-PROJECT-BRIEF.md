# Final Project Brief — Build and Publish a Simple Website

**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Week:** 8 | **Project assessment:** 30 marks  
**Student:** __________________________  **Date:** ______________

## 1. Project purpose

Plan, build, test and present a simple website using an AI assistant as a helper. You must review and edit the generated code, organise your project files, create a GitHub repository and attempt an approved deployment.

Choose one project:
- A personal learning portfolio using only information and images you are comfortable publishing; or
- An academy information website using only content and branding approved by the academy.

## 2. Required pages or sections

Your website must include:
1. **Home:** clear title and short introduction.
2. **About:** purpose of the site or project.
3. **Services/Courses:** a simple list of services or course information.
4. **Contact:** approved contact information or a clearly labelled non-functional example contact layout.

You may use one-page sections or separate pages, depending on instructor guidance.

## 3. Technical requirements

- HTML for page structure.
- CSS for appearance and layout.
- JavaScript may be used for a simple feature if taught and understood.
- Clear navigation links.
- Readable text and suitable images.
- Responsive layout that works on desktop and a narrow mobile screen.
- Meaningful page title and image alternative text.
- Working internal and external links.
- Project files organised in a clear folder.
- A README explaining the project and how to view it.

A static HTML form does not send a message by itself. Do not label it “working” unless a backend or approved form service has been configured and tested.

## 4. Suggested project structure

```text
my-website/
├── index.html
├── about.html
├── courses.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

Your instructor may approve a simpler one-page structure. Do not create unnecessary files that you cannot explain.

## 5. AI use and code understanding

You may ask an AI assistant to help plan the site, draft HTML/CSS/JavaScript, explain an error or suggest improvements. You must:
- Write a prompt that explains the audience, purpose and requirements.
- Review the generated code before using it.
- Test the page in a browser.
- Edit at least the text, styles and one other meaningful part.
- Check mobile layout and links.
- Ask the AI to explain code in simple terms, then verify the explanation.
- Disclose meaningful AI assistance in your project notes.

Do not paste passwords, API keys, private student data or confidential academy information into an AI tool.

## 6. Testing checklist

- [ ] Home page/section opens.
- [ ] About section is present.
- [ ] Services/Courses section is present.
- [ ] Contact section is present and accurately described.
- [ ] Navigation links work.
- [ ] Images load and have useful alt text.
- [ ] Text is readable and spelling is checked.
- [ ] Layout works at desktop width.
- [ ] Layout works at a narrow mobile width.
- [ ] No private information or secrets are published.
- [ ] AI-generated code has been reviewed and edited.
- [ ] README explains the project.
- [ ] Repository contains the correct files.
- [ ] Deployment is tested, or the deployment worksheet explains what remains.

## 7. GitHub and deployment

1. Create a repository using an instructor-approved account.
2. Choose public/private visibility according to the assignment and academy policy.
3. Upload only files approved for sharing.
4. Write a README with project purpose, features, files and instructions.
5. Commit changes with clear messages.
6. Deploy using GitHub Pages or another instructor-approved static host if access is available.
7. Open the live URL in a private/incognito window or another device to test it.
8. If deployment is unavailable, submit the repository-ready project and a completed deployment plan. Do not invent a URL.

## 8. Presentation

Prepare a 3–5 minute presentation:
- What is your website for?
- Who is the intended audience?
- Which pages or sections did you create?
- What did you change after AI generated the first version?
- How did you test the website?
- What did you learn about GitHub and publishing?
- What AI help did you use, and what did you verify?

Be ready to explain the purpose of the HTML, CSS and JavaScript files in simple words.
