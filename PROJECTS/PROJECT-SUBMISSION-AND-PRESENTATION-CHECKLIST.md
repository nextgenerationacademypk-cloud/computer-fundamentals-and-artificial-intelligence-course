# Project Submission and Presentation Checklist

Use this checklist for weekly projects and the Week 8 final website project.

## Before submitting

- [ ] My files are saved in the correct course folder.
- [ ] File names clearly describe their contents.
- [ ] I opened the files again to confirm they work.
- [ ] My work follows the task instructions.
- [ ] I used fictional data where practice data was required.
- [ ] I checked spelling, layout and links.
- [ ] I have not included passwords, verification codes, private student data or confidential files.
- [ ] I have permission to use any image, logo, text or audio included.
- [ ] I can explain the main steps I completed.
- [ ] I have described meaningful AI assistance honestly.

## If submitting to GitHub

- [ ] The repository name is clear.
- [ ] I selected visibility with instructor guidance.
- [ ] The repository contains only approved files.
- [ ] The README explains the project.
- [ ] No secret keys, tokens, passwords or private information are included.
- [ ] Commit messages describe the changes.
- [ ] I checked that the uploaded files open correctly.

## If publishing a website or digital media

- [ ] I tested the content on the intended device.
- [ ] I checked the mobile layout where relevant.
- [ ] I verified links and sources.
- [ ] I checked that no private information is visible.
- [ ] I obtained required permission for names, photographs, logos and voices.
- [ ] I did not claim that a feature works unless I tested it.
- [ ] I recorded the actual live URL only after successful deployment.

## Presentation preparation

1. Explain the purpose of your project.
2. Show the main output.
3. Describe two decisions you made.
4. Explain one problem and how you solved it.
5. State what you checked or verified.
6. Explain any AI help you used.
7. Share one thing you would improve next.
