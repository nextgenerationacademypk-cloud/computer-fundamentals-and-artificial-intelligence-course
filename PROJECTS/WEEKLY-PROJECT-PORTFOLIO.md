# Weekly Project Portfolio

The weekly projects help students turn lesson skills into practical evidence. The instructor should adapt task size to available lesson time and ensure every student completes an individual contribution.

## Project sequence

| Week | Project | Student output | Main skills |
|---|---|---|---|
| 1 | Label a computer system | Labelled system-unit diagram and component explanation | Hardware identification, safe handling |
| 2 | Organised digital workspace | Course folder structure, saved files and a ZIP archive | Windows, file/folder management |
| 3 | Safe computer and network investigation | Task Manager observations, storage diagram, network map and phishing response | System observation, storage, networking, browser/email safety |
| 4 | Academy Student Record Package | Word report, fictional Excel register/marks workbook and PowerPoint presentation | Office productivity and digital ethics |
| 5 | Tested Prompt Library | At least 15 useful prompts with before/after examples and test notes | Prompt engineering, Prompt Coach, verification |
| 6 | Research and Office Productivity Pack | Source-based NotebookLM study guide, document, spreadsheet and presentation | Research, citations, AI-assisted office work |
| 7 | Educational Digital Content Pack | Educational poster, thumbnail, channel/content plan and short-video prototype | Visual communication, AI media and responsible publishing |
| 8 | Website and GitHub Portfolio | Responsive site, repository, README and deployment evidence | HTML/CSS/JS awareness, AI-assisted code review, GitHub and publishing |

## Project requirements

Every project should have:
- A clear purpose and simple task instructions.
- A saved output in the student's course folder.
- Evidence that the student performed or understood the work.
- A short reflection: what worked, what was difficult and what was checked.
- Instructor feedback and a follow-up task where needed.

## Safe data and publication

- Use fictional names, marks, contact details and records.
- Do not use real student data in public tools or sample spreadsheets.
- Do not publish private contact information or unapproved photographs.
- Check image and text reuse permissions.
- Do not include passwords, tokens, API keys or private network details.
- Do not claim that a static form works unless it has a real approved backend/service and has been tested.

## Instructor review

Use the relevant weekly assessment rubric in the week folder. Weekly project evidence contributes to the approved overall course assessment; do not add weekly 50-mark assessments together as a separate course total.
