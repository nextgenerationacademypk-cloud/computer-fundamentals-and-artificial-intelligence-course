# Projects and Practical Portfolio

This folder contains the integrated project pathway and the final project instructions. Each week's detailed lessons and practical workbook contain the relevant guided activities.

## Project resources

- [Weekly Project Portfolio](WEEKLY-PROJECT-PORTFOLIO.md) — project outcome for each of the eight course weeks.
- [Final Website Project Brief](FINAL-WEBSITE-PROJECT-BRIEF.md) — Week 8 project requirements, AI-use expectations, file structure, GitHub/deployment steps and 30-mark rubric.
- [Project Submission and Presentation Checklist](PROJECT-SUBMISSION-AND-PRESENTATION-CHECKLIST.md) — student submission, publication safety and presentation preparation.

## Weekly project pathway

1. Week 1: labelled computer system-unit diagram.
2. Week 2: organised digital workspace.
3. Week 3: safe system and network investigation.
4. Week 4: Academy Student Record Package (Word, fictional Excel data and PowerPoint).
5. Week 5: tested Prompt Library.
6. Week 6: source-based research and Office productivity package.
7. Week 7: educational digital content pack.
8. Week 8: responsive website, GitHub repository and deployment evidence.

## Project quality expectations

- Students must make and explain their own contribution.
- Use fictional data in practice.
- Check AI-generated content, formulas and code.
- Respect copyright, privacy and publication permissions.
- Keep passwords, tokens, private student information and confidential academy files out of public repositories.
- Do not claim a static contact form works unless a backend or approved service is configured and tested.
- Do not invent a live deployment URL.
