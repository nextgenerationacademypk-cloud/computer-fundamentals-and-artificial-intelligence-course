## Required Prompt Coach practical evidence
Students receive a rough request such as “Make a presentation about computers.” They must:
- Identify missing context and audience.
- Improve the prompt manually or with Prompt Coach.
- Review the rewritten prompt for invented assumptions.
- Choose a suitable version and test it.
- Explain one improvement and one limitation.

This evidence is assessed within the existing 4-mark prompt-construction and 3-mark iteration criteria; it does not add marks or change the 50-mark total.
