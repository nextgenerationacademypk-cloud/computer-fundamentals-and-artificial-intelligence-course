# Keyboard Shortcuts and File Organisation — Student Reference

Shortcuts help you work faster, but first learn what each action does. Windows and application versions may differ.

## 1. Useful Windows shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + C | Copy selected item |
| Ctrl + X | Cut selected item |
| Ctrl + V | Paste |
| Ctrl + Z | Undo last action |
| Ctrl + A | Select all in the current area |
| Ctrl + S | Save |
| Ctrl + P | Print |
| Ctrl + F | Find |
| Alt + Tab | Switch between open apps |
| Windows key | Open Start |
| Windows + E | Open File Explorer |
| Windows + L | Lock the computer |
| Ctrl + Shift + Esc | Open Task Manager |
| F2 | Rename selected file (in File Explorer) |
| Delete | Move selected file to Recycle Bin in common File Explorer use |
| Shift + Delete | Bypass Recycle Bin — avoid unless instructor specifically explains and approves |

## 2. Useful browser shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + T | Open a new tab |
| Ctrl + W | Close current tab |
| Ctrl + Shift + T | Reopen recently closed tab |
| Ctrl + L | Select address bar |
| Ctrl + R | Refresh page |
| Ctrl + D | Bookmark current page |
| Ctrl + H | Open browser history (browser-dependent) |
| Ctrl + J | Open downloads (browser-dependent) |

Do not use a shortcut if you do not understand its effect. On shared computers, do not save passwords or leave personal accounts signed in.

## 3. File and folder basics

A **file** stores information, such as a document, picture or spreadsheet. A **folder** helps organise files. A **file extension** is the ending of a file name, such as .docx, .xlsx, .pptx, .pdf, .jpg or .html. The extension often indicates the file type.

Common actions:
- **Create:** make a new folder or file.
- **Rename:** give an item a clearer name.
- **Copy:** make another copy while keeping the original.
- **Move:** change where an item is stored.
- **Delete:** remove an item; it may go to Recycle Bin.
- **Restore:** return an item from Recycle Bin if it is still available.
- **ZIP:** place files into a compressed archive.
- **Extract:** unpack files from an archive.

## 4. Good file names

Use names that describe the content. Examples:
- `W01-Hardware-Identification.docx`
- `W04-Excel-Practice.xlsx`
- `W06-Research-Summary.pdf`
- `W08-Portfolio-Website-README.md`

Avoid names such as `newfile-final-final2.docx` or names that reveal private information. Use dates only when they help identify versions, for example `2026-11-07`.

## 6. Safe file handling

- Save before closing a program.
- Keep the original when editing an important file; work on a copy if instructed.
- Check the file name and folder before saving.
- Do not open unexpected attachments.
- Do not download software from pop-ups.
- Do not delete system files or unfamiliar folders.
- Use the academy-approved backup location.
- Ask before formatting or erasing any storage device.
