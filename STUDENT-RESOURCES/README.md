# Student Resources

These resources help students prepare for lessons, practise safely, organise their work and track progress through the **Computer Fundamentals and Artificial Intelligence Foundation Course**.

## Student handbook and references

- [Student Orientation Handbook](STUDENT-ORIENTATION-HANDBOOK.md) — course overview, learning expectations, assessment, folder organisation, safety and how to ask for help.
- [Digital Safety and Responsible AI Guide](DIGITAL-SAFETY-AND-RESPONSIBLE-AI-GUIDE.md) — account safety, phishing, privacy, safe publishing and checking AI output.
- [Keyboard Shortcuts and File Organisation](KEYBOARD-SHORTCUTS-AND-FILE-ORGANIZATION.md) — common Windows/browser shortcuts, file types, folder structure and safe file handling.
- [Student Study Planner and Progress Tracker](STUDENT-STUDY-PLANNER-AND-PROGRESS-TRACKER.md) — weekly learning plan, practical skill checklist, homework record and final project planning.

## How to use these resources

1. Read the orientation handbook during the first course sessions.
2. Keep the digital safety guide available during internet and AI activities.
3. Practise shortcuts gradually; learn what each shortcut does before using it.
4. Update the planner after lessons and ask the instructor to help review progress.
5. Follow the instructor's folder and file-naming instructions if they differ from the examples.

## Student privacy

The planner is for learning reflection. Keep personal marks and confidential feedback private. Do not upload completed student records to a public repository or share them with an AI service. Use fictional examples in public demonstrations.
