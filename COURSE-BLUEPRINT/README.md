# Official Course Blueprint

## 1. Course identity

**Official title:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Institution:** Next Generation Academy  
**Location:** Seni Gumbat, Kohat, Pakistan  
**Duration:** 8 weeks  
**Schedule:** 5 lessons per week, 2 hours per lesson  
**Total:** 40 lessons / 80 guided hours  
**Level:** Beginner  
**Delivery:** Instructor-led classroom and computer-lab instruction  
**Language:** Simple English  
**Learning approach:** Approximately 80% practical work and 20% theory

## 2. Course purpose

The course helps beginners become confident, safe and productive computer users. Learners develop practical skills in computer hardware, Windows, internet use, office applications and responsible artificial intelligence. They finish by using AI as an assistant to plan, build, inspect, publish and present a simple website.

## 3. Intended learners and entry requirements

The programme is designed for beginners. No programming experience is required. Students should be willing to practise, follow lab safety instructions and complete independent tasks. Instructors should assess basic keyboard, mouse and file-management confidence at the start and provide additional support where needed.

## 5. Course learning outcomes

By the end of the programme, a successful learner should be able to:

1. Explain basic computer concepts and identify common hardware components.
2. Operate a Windows computer and manage files and folders safely.
3. Explain basic storage, installation, internet and networking concepts.
4. Create and format useful documents, spreadsheets and presentations.
5. Explain core AI concepts, limitations, privacy concerns and responsible-use principles.
6. Write, test and improve clear prompts for common learning and productivity tasks.
7. Use selected AI tools to support research, office work and digital content creation while checking outputs.
8. Plan and build a simple responsive website with AI assistance, understand the generated files at a basic level, upload a project to GitHub and publish it.
9. Present practical work and explain their own contribution.

## 6. Standard two-hour lesson model

A typical lesson uses:
- **20 minutes:** explanation, vocabulary and instructor demonstration.
- **90 minutes:** guided practice, independent practice and troubleshooting.
- **10 minutes:** review, evidence of learning and exit check.

This is a planning model, not a rigid rule. Instructors may adjust timing for safety-critical demonstrations, student needs or assessment while preserving the practical emphasis.

## 7. Teaching and inclusion principles

- Demonstrate a task before asking beginners to perform it.
- Break complex work into small, visible steps.
- Use plain English and explain technical vocabulary.
- Give every learner meaningful hands-on computer time.
- Pair students thoughtfully; rotate keyboard and mouse roles.
- Provide extension tasks for faster learners and step-by-step support for learners who need it.
- Assess what learners can do, not only what they can recall.
- Never let AI replace the learner's own practice or understanding.

## 9. Final project

Each learner creates a simple personal portfolio or academy information website containing Home, About, Services/Courses and Contact sections. The site should have clear navigation, suitable images, working links and a responsive layout. Learners inspect and edit AI-generated code, upload the project to GitHub and publish it. GitHub Pages is the primary deployment route; alternatives may be introduced if appropriate.

## 10. Equipment and software

Recommended facilities include a computer for each learner where possible, instructor computer, projector/display, reliable power, internet access, peripherals, a safe hardware demonstration unit and spare computer or virtual machine for operating-system installation practice.

Use licensed Microsoft Office where available. LibreOffice may be used as an alternative, with interface differences explained. Use official software sources and prepare offline practice files in case internet access is interrupted.

## 11. Safety, privacy and academic integrity

- Supervise all hardware handling and Windows installation.
- Never open a PSU. Disconnect power before opening a desktop case and use ESD precautions.
- Never format or repartition a learner's personal drive as a classroom exercise.
- Use training accounts and fictional data for demonstrations.
- Do not enter sensitive personal, financial, medical or student information into public AI tools.
- Verify AI-generated facts, citations, formulas, images and code.
- Respect copyright, licensing, consent and attribution requirements.
- Students remain responsible for understanding and presenting submitted work.

## 12. Quality assurance

Before delivery, the instructor should test software and links, inspect lesson files, prepare practical resources, check accessibility and safety, and confirm assessment criteria. After delivery, review student performance, note technical issues and update materials where needed. Tool-specific instructions should be rechecked because software interfaces and AI service availability change.
