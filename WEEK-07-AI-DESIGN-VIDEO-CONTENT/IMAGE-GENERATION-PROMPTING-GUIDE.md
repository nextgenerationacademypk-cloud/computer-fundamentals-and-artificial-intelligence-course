# Image Generation and Prompting Guide
## Adapted for Next Generation Academy — Week 7, Lesson 31

**Level:** Beginner  
**Purpose:** A practical reference for planning, generating, editing and checking images with an AI image tool.

This guide adapts useful ideas from the supplied *Prompt Engineering Tutorial for Nano Banana*. It keeps the strongest teaching ideas—specific descriptions, composition, lighting, visual style, reference images, layered refinement and quality checks—and expands them beyond portrait photography to educational visuals and design work.

The guide is tool-neutral. Nano Banana is one example; other image tools may use different controls, names, age rules, limits and output settings.

## 1. The main idea: describe the image you need

A useful image prompt tells the tool what to create and why. Do not add technical words just to make a prompt look professional. Choose details that actually help the intended image.

A beginner-friendly prompt can follow this order:

1. **Task and purpose:** What should be created, and what will it be used for?
2. **Main subject:** Who or what must be visible?
3. **Action or relationship:** What is happening? How do objects relate?
4. **Setting:** Where does the scene take place?
5. **Composition:** What should be large, close, far away, centred or left/right?
6. **Style:** Photograph, clean vector illustration, 3D render, watercolor, cartoon, diagram, etc.
7. **Lighting and mood:** Bright and friendly, soft daylight, dramatic side light, calm and professional.
8. **Format:** Landscape, square or portrait; include an aspect ratio if useful and supported.
9. **Text and layout needs:** Give exact wording in quotation marks, or ask for clear empty space where text will be added later.
10. **Important limits:** State what must stay unchanged, what must be excluded, and any safety or accuracy requirements.

### Reusable prompt template

Copy this template and replace the bracketed instructions:

```text
Create a [TYPE OF IMAGE] for [PURPOSE AND AUDIENCE].

Main subject: [WHAT MUST BE SHOWN].
Action/relationship: [WHAT IS HAPPENING].
Setting: [BACKGROUND OR LOCATION].
Composition: [VIEW, FRAMING, POSITION AND EMPTY SPACE].
Visual style: [PHOTOGRAPH / VECTOR / ILLUSTRATION / OTHER].
Lighting and mood: [LIGHT QUALITY AND FEELING].
Format: [LANDSCAPE / SQUARE / PORTRAIT; ASPECT RATIO IF NEEDED].
Text: [EXACT WORDS IN QUOTATION MARKS, OR "NO TEXT"].
Keep: [DETAILS THAT MUST REMAIN].
Avoid: [UNWANTED ELEMENTS OR ERRORS].
```

Not every prompt needs all ten parts. Start with the important details and add more only when they improve the result.

## 2. Three ways to write a prompt

### A. Natural paragraph

Best for beginners and most everyday tasks.

**Example — classroom illustration**

"Create a clean, friendly educational illustration for beginner computer students. Show a student safely using a desktop computer at a tidy classroom desk. Include a monitor, keyboard and mouse, with a teacher nearby. Use a simple modern vector style, clear shapes, balanced composition and bright natural classroom lighting. Landscape 16:9. No words, logos or watermarks."

### B. Labelled prompt

Useful when a task has several requirements.

```text
PURPOSE: Explain safe computer use to beginners.
SUBJECT: A student using a desktop computer.
SETTING: A bright, tidy computer lab.
COMPOSITION: Medium-wide view; computer and student clearly visible.
STYLE: Clean educational vector illustration.
LIGHTING: Soft daylight; friendly and calm.
FORMAT: Landscape 16:9.
TEXT: No text; leave a small clear area for a caption.
```

### C. Structured data / JSON

This is optional. It may help when a tool or workflow specifically accepts structured input, but students do not need JSON to write a good image prompt. A normal sentence or labelled prompt is usually easier to understand and edit.

## 3. Composition: decide what viewers notice first

Composition means how the subjects and objects are arranged inside the image.

| Term | Simple meaning | When it helps |
|---|---|---|
| Close-up | Shows a small part in detail | A face, hand, component or product detail |
| Medium shot | Shows a subject and some surroundings | A person demonstrating a task |
| Wide shot | Shows more of the environment | A classroom, office or landscape |
| High angle | Camera looks down | Showing a desk, layout or objects |
| Low angle | Camera looks upward | Making a subject feel prominent |
| Rule of thirds | Place important elements near a third-line intersection | Creating a balanced, less static image |
| Negative space | Deliberately empty space | Leaving room for a headline or logo to be added later |
| Leading lines | Lines guide the viewer's eye | Directing attention towards the main subject |

**Practical tip:** For a poster background, ask the tool to place the main subject on one side and leave clean negative space on the other side. Then add the real headline and details in a design editor.

## 4. Lighting and mood

Lighting changes how an image feels. Students can begin with everyday descriptions:

- **Soft light:** gentle shadows; useful for friendly portraits and clear educational scenes.
- **Hard light:** strong, sharp shadows; useful for dramatic effects.
- **Side lighting:** light comes from one side and reveals shape and texture.
- **Backlighting / rim light:** light comes from behind and outlines the subject.
- **Window light:** natural-looking light from a window.
- **Golden-hour light:** warm light near sunrise or sunset.
- **High-key look:** bright image with light backgrounds and gentle shadows.
- **Low-key look:** darker image with controlled highlights and deeper shadows.

### Optional photography vocabulary

Use these terms only when a photographic look is required:

- **85mm lens look:** often used as a portrait-photography style cue.
- **35mm lens look:** often suggests a wider view that includes more surroundings.
- **Shallow depth of field:** subject appears sharp while the background is blurred.
- **Bokeh:** the visual quality of out-of-focus highlights.
- **Rembrandt lighting:** a classic portrait-lighting pattern with a small triangle of light on the shadowed cheek.

Camera and lens terms are creative instructions, not a guarantee that the AI tool will simulate a real camera accurately. Beginners do not need to memorise camera models, ISO values or aperture numbers.

## 5. Image format and aspect ratio

Choose the shape that suits the destination. These are common starting points, not fixed platform rules:

| Shape | Common ratio | Possible use |
|---|---:|---|
| Landscape | 16:9 | Presentation slide, video frame, website banner |
| Square | 1:1 | Square social post or profile graphic |
| Portrait | 4:5 | Vertical feed graphic |
| Tall vertical | 9:16 | Short-video frame or vertical story |

Check the current platform or editor specifications before final export. Some tools offer aspect-ratio controls separately from the text prompt. If so, use the actual control rather than relying only on prompt wording.

## 6. Generating a new image vs editing an existing image

These are different tasks.

### Generate a new image

Describe the complete scene: subject, setting, style, composition and purpose.

### Edit an existing image

Tell the tool:
- What to change.
- Exactly where or on which object the change should happen.
- What must remain the same.
- Whether the overall composition, subject identity, background, colours or style must be preserved.

**Example — careful edit**

"Change only the colour of the backpack from red to dark blue. Keep the student's pose, face, clothing, classroom background, lighting and camera view unchanged."

A good editing instruction is specific. Avoid saying only "make it better".

## 7. Reference images: explain the role of each image

If a tool accepts reference images, tell it what each image is for. For example:

- Image A: use only as a reference for the person's pose.
- Image B: use for the colour palette and illustration style.
- Image C: use for the product shape.

Do not assume the tool will preserve every detail perfectly. Review the result.

**Privacy and consent:** Use a person's photograph only when you have the required permission and a legitimate purpose. Never upload private student photos, identity documents or confidential records to an unapproved service. Do not use a real person's likeness to create a misleading, embarrassing or deceptive image. For classroom practice, use instructor-approved sample images or fictional subjects.

**Age and account rules:** Image-generation and image-editing features can have different minimum-age rules. School accounts may also have restrictions. The instructor must check the current provider rules and academy policy. Do not ask a student to bypass a restriction or create an account using a false age. If students are not eligible, use instructor demonstrations or prepared sample images.

## 8. Text inside generated images

Some newer tools can render text more accurately than earlier image generators, but spelling, punctuation, names, numbers and small labels can still be wrong.

For a design with important wording:
1. Write and proofread the wording first.
2. Put the exact wording in quotation marks in the prompt.
3. Ask for a clear, simple text layout.
4. Inspect every letter and number.
5. Correct the final text in a design editor before publication.

For a complex poster, infographic or academy announcement, it is often better to generate the visual background separately and add the final text in Canva, PowerPoint, LibreOffice Impress or another editor.

Never publish an image with unverified dates, prices, phone numbers, names or claims.

## 9. Improve the result in small steps

Do not rewrite the entire prompt every time. Use this simple loop:

1. Generate a first draft.
2. Compare it with the purpose and prompt.
3. Identify the biggest problem.
4. Change one or two details only.
5. Generate or edit again.
6. Compare the new result with the previous version.
7. Keep the best version and record what changed.

**Example sequence**

- First request: "Create an educational illustration of a computer lab."
- Improvement: "Show only three students and one instructor; make the computers clearly visible."
- Improvement: "Move the instructor to the right and leave open space on the left for a title."
- Final check: inspect hands, screens, cables, labels, spelling, composition and suitability.

For image editing, add a preservation instruction such as: "Keep everything else unchanged."

## 10. Examples students can adapt

### Example 1 — educational diagram

"Create a simple educational infographic explaining the input-process-output-storage cycle of a computer. Use four clearly separated stages with simple icons and arrows. Use accurate labels: 'Input', 'Processing', 'Output' and 'Storage'. Clean flat vector style, high contrast, landscape layout. Check that the stages are in the correct order and all labels are spelled correctly."

**Important:** Check the educational facts and labels against the lesson notes. A visually attractive diagram can still be wrong.

### Example 2 — professional portrait

"Create a professional head-and-shoulders portrait of the consenting adult in the supplied reference photo. Keep the person's appearance recognisable and natural. Use a simple neutral background, neat professional clothing, soft studio-style lighting and a friendly expression. Keep the result realistic and avoid heavy retouching."

Use only a reference photo that the person has authorised for this purpose. Do not use student photos as a routine classroom exercise.

### Example 3 — poster background

"Create a modern poster background for a beginner digital-skills workshop. Show a laptop and simple technology-themed objects on the right side. Use a clean professional blue-and-white colour palette. Leave generous empty space on the left for a headline and event details. Portrait 4:5. Do not generate words, logos or dates."

Add the real academy-approved text in a design editor.

### Example 4 — video thumbnail

"Create a clear YouTube thumbnail background for a beginner lesson about organising files in Windows. Show a tidy computer desktop and a large folder icon as the main focus. Use strong contrast and a simple uncluttered layout. Leave empty space for a short title to be added later. Landscape 16:9. No words or logos."

### Example 5 — edit one detail

"Change only the background from a busy office to a simple light-grey studio background. Keep the subject, clothing, pose, face, lighting direction and framing unchanged."

## 11. Common mistakes and how to improve them

| Mistake | Better approach |
|---|---|
| "Make a nice picture" | State the purpose, subject and style |
| Too many unrelated details | Prioritise the main subject and message |
| Conflicting styles | Choose one main style and explain any intentional mix |
| No composition instruction | State framing, subject position and empty space |
| Camera terms added without purpose | Use only one or two relevant photography cues |
| Important text left unchecked | Proofread and correct it in an editor |
| Editing request says only "improve it" | State exactly what to change and what to preserve |
| First output accepted without review | Inspect, refine and compare variations |
| Reference photo used without permission | Use approved or fictional reference material |

## 12. Image quality and responsible-use checklist

Before using an image in a project, check:

- [ ] Does it communicate the intended message?
- [ ] Is the main subject clear and suitable for the audience?
- [ ] Is the composition balanced and is the focal point easy to see?
- [ ] Are faces, hands, objects, screens, labels and background details plausible?
- [ ] Are important facts, names, numbers and words correct?
- [ ] Does the aspect ratio suit the intended use?
- [ ] Is the image readable on a phone or classroom screen?
- [ ] Do we have the rights or permission needed for the input and output?
- [ ] Has the use of a person's likeness been authorised?
- [ ] Have private details been removed?
- [ ] Have the tool's current terms and publication rules been checked?
- [ ] Is the image clearly disclosed as AI-generated when needed to avoid misleading viewers?

## 13. Suggested classroom practice

1. Write a vague prompt for an educational visual.
2. Improve it using the prompt template.
3. Generate or inspect a supplied sample.
4. Identify three strengths and three errors.
5. Revise one or two prompt details.
6. Compare the first and revised result.
7. Explain which change improved the image and why.

**Evidence to save:** original prompt, improved prompt, first draft or sample, revised result, and completed quality checklist.
