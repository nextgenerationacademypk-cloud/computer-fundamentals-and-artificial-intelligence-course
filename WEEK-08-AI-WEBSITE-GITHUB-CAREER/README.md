# Week 8 — AI-Assisted Website Development, GitHub and Career Readiness

**Course:** Computer Fundamentals and Artificial Intelligence Foundation Course  
**Academy:** Next Generation Academy  
**Duration:** 5 lessons / 10 guided hours  
**Level:** Beginner  
**Teaching approach:** Approximately 20% explanation and 80% practical work

## Week purpose
Students plan, build, test, organise and present a small static website with AI assistance. They learn HTML, CSS and JavaScript basics, use GitHub to store project files and publish with GitHub Pages where account eligibility and internet access allow.

## Suggested weekly delivery
- Day 1: Website foundations, planning and workspace (Lesson 36)
- Day 2: AI-assisted website building and testing (Lesson 37)
- Day 3: GitHub repositories, commits and README (Lesson 38)
- Day 4: Static website deployment and testing (Lesson 39)
- Day 5: Final project, presentation and career readiness (Lesson 40)

Each lesson uses a 120-minute structure: 20 minutes explanation, 90 minutes demonstration/practical work and 10 minutes review.

## Final project
Create a personal portfolio or academy information website with Home, About, Services/Courses and Contact. Include navigation, suitable approved images, working links, responsive layout and readable content. Students must inspect and edit AI-generated code, explain the main HTML/CSS parts, upload the project to GitHub, create a README and publish with GitHub Pages where possible.

A static contact form does not send messages unless a backend or approved form service is configured. Do not present a non-functional form as working.

## Equipment and preparation
- Computer with browser and Visual Studio Code or another suitable editor.
- Internet access for AI and GitHub demonstrations where available.
- Instructor demonstration repository and backup local website.
- Approved image assets and sample website content.
- Offline alternative for connectivity or account restrictions.

## Safety and responsible use
- Never enter passwords, API keys, recovery codes or private student data into AI prompts or public repositories.
- Follow current GitHub account terms and use suitable account protection.
- Public websites can be copied and shared; obtain academy approval before publishing official details, logos or photographs.
- Verify generated code, links, content and assets.
- Disclose AI assistance honestly and understand the code being submitted.
- Check current GitHub Pages and hosting rules before delivery; interfaces and eligibility can change.

## Completion evidence
Students submit project folder, README, repository URL, live URL if deployed (or deployment-ready evidence), test/change log, presentation and responsible-use checklist.
