# Week 8 — AI-Assisted Website Development, GitHub and Career Readiness

**Lessons:** 36–40

36. Introduction to AI-Assisted Website Development
37. Building a Website with a Large Language Model
38. GitHub Fundamentals and Project Management
39. Website Deployment and Online Publishing
40. Final Project, Presentation and Career Readiness

Final project: a simple responsive personal portfolio or academy information website with Home, About, Services/Courses and Contact sections. Students must inspect and edit generated code, upload the project to GitHub, publish it and explain their own contribution.

GitHub Pages is the primary deployment route; other services are optional alternatives.
