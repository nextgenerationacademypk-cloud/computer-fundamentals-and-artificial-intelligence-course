## Instructions for students

- Read each task before starting.
- Use only the computer and software approved by your instructor.
- Ask if an instruction is unclear.
- Save your work in the folder specified by the instructor.
- Do not change system settings, install software or use private data unless instructed.
- Work safely. The instructor may stop an unsafe action.

## Task 2 — Windows and file management (3 marks)

1. Open File Explorer.
2. Create a folder named `Mid-Course-Practice`.
3. Create a text/document file named `My-Practice-Notes`.
4. Save it in the correct folder.
5. Reopen or locate the file to show that it was saved.

**Marks:** folder created /1; file saved in correct place /1; locates and explains file /1.

## Task 3 — Internet and email (2 marks)

1. Open the approved browser and visit the instructor-provided safe website.
2. Identify the domain in the address bar.
3. Draft a professional email with a subject, greeting, clear message and closing. Do not send until the instructor checks it.

**Marks:** safe browser/domain check /1; clear email draft /1.

## Task 4 — Word (2 marks)

Create a short document with a title, one paragraph, a bulleted list and readable formatting. Save it using the instructed file name.

**Marks:** content and structure /1; formatting and save /1.

## Task 5 — Excel (3 marks)

Enter a small fictional table with three items and values. Use a SUM formula to calculate the total. Format the heading and show the instructor the formula.

**Marks:** accurate data /1; correct formula/result /1; readable formatting /1.

## Task 6 — PowerPoint (2 marks)

Create two slides about a computer safety topic. Use a clear title, short points and at least one relevant visual. Keep the slides readable.

**Marks:** content and visual /1; readability and presentation /1.

## Fairness and contingency

- Give all students equivalent tasks and comparable time.
- Use fictional data and approved accounts.
- If a workstation fails, pause and provide an equivalent working station or reschedule the affected task.
- Do not penalize a student for an unavailable paid account or internet service if the skill can be assessed another way.
- Record accommodations or alternative evidence according to academy policy.
