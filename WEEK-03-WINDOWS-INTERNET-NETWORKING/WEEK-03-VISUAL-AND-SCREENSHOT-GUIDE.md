Conceptual diagrams are embedded in the five lesson files. Real Windows screenshots must be captured from an academy-controlled device; do not fabricate screenshots or imply that a conceptual diagram is an actual Windows screen.

## Capture quality standard
1. Capture at readable resolution and crop irrelevant desktop areas.
2. Keep cursor away from important text.
3. Use consistent file names, for example W03-L11-task-manager-performance.png.
4. Add concise alt text and a one-sentence caption.
5. Add arrows or numbered labels only when they improve understanding.
6. Do not show passwords, verification codes, email addresses, student names, serial numbers, licence keys or sensitive network details.
7. Obtain permission before photographing people or personal property.
8. Use academy-created images or assets with clear reuse permission. Record source and licence for third-party images.

## Suggested file locations
Store approved assets in this week folder or a clearly named assets/ subfolder. Use relative image paths in lesson Markdown, for example:

![Task Manager Performance view showing system resource graphs](assets/W03-L11-task-manager-performance.png)

Do not add this embed until the exact image file has been uploaded and checked.
