# Week 3 — Windows Management, Installation, Internet and Networking

**Lessons:** 11–15

11. Task Manager, Device Manager and Drivers
12. Disk Management, Partitions and File Systems
13. Windows Installation and BIOS/UEFI
14. Internet and Computer Networks
15. World Wide Web, Browsers and Online Communication

Practical emphasis: system diagnostics, storage concepts, supervised installation demonstration, safe networking investigation, browser and email skills.

Safety: Windows installation and partition work must use a spare training computer or virtual machine. Back up data first. No unsupervised formatting or partition deletion.
