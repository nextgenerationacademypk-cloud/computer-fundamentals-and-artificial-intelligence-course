# Week 3 Quiz Bank — Student Copy

**Lessons 11–15 | Suggested time:** 30–40 minutes

## Lesson 11 — Task Manager, Device Manager and Drivers
1. Which keyboard shortcut opens Task Manager?
2. Name four areas shown in Task Manager's Performance view.
3. What is a process?
4. Why does high CPU usage not always mean the computer is faulty?
5. What does a device driver do?
6. Name two safer sources for approved driver updates.
7. What might a yellow warning icon in Device Manager indicate?
8. Why should a beginner avoid ending unfamiliar processes?
9. What should a troubleshooting report record?
10. A pop-up offers a free driver updater. What is the safe response?

## Lesson 12 — Disk Management, Partitions and File Systems
1. What is a physical disk?
2. Explain a partition in simple words.
3. Does each drive letter always represent a separate physical disk?
4. Which file system is commonly used for Windows internal drives?
5. What is the FAT32 individual-file size limit?
6. Give one reason to use exFAT on removable storage.
7. What do MBR and GPT describe?
8. What is one risk of formatting a volume?
9. Why is another folder on the same disk not a reliable backup?
10. Name three checks before a real partition change.

## Lesson 13 — Windows Installation and BIOS/UEFI
1. What is firmware?
2. What role does UEFI play when a computer starts?
3. Explain the difference between an upgrade and a clean installation.
4. Does every Windows reset option keep files and apps?
5. Where should installation media be obtained?
6. Does Windows installation itself provide a licence?
7. Why must the target disk be confirmed?
8. Where may students practise installation?
9. What must be completed before destructive partition actions?
10. What should you do if the setup screen differs from the instructor's steps?

4. What does an ISP provide?
5. What is the main role of a router?
6. Does Wi-Fi connected always mean the internet is working?
7. What does an IP address help identify?
8. What does DNS do?
9. What is bandwidth?
10. Why must Wi-Fi passwords not appear in public screenshots?

## Lesson 15 — World Wide Web, Browsers and Online Communication
1. Explain the difference between the internet and the Web.
2. What is a browser?
3. How is a search engine different from a browser?
4. What is a URL?
5. What does HTTPS help protect?

7. What is website hosting?
8. What should a good email subject line do?

## Mixed application
1. A computer is slow while Windows Update is running. Which tool can help you observe activity? What should you avoid doing?
2. Disk 0 shows C: and D:. Can you conclude there are two physical drives? Explain.
3. An email says your academy account will close in 10 minutes unless you sign in through a link. Identify two warning signs and state a safe response.
4. Wi-Fi is connected but a website will not open. List three safe checks.
5. A friend wants to reinstall Windows on their only laptop. What questions and safety checks must happen first?

## Short practical assessment
- Open Task Manager and identify CPU, memory, disk and network.
- Open Device Manager and locate network adapters.
- Explain a sample Disk Management screenshot without changing it.
- Label a network diagram.
- Identify the domain in a sample URL.
- Draft a professional email and identify phishing signals.
